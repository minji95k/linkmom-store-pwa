# 직원용 시작 안내

## 1. 접속 주소로 들어가기

관리자에게 전달받은 Production 접속 주소로 들어갑니다.

## 2. 로그인

- 관리자에게 전달받은 **이메일**과 **초기 비밀번호**로 로그인합니다.

## 3. 비밀번호 바꾸기 (최초 1회 필수)

- 로그인 후 하단 **MY** 탭 → **비밀번호 변경**에서 나만 아는 비밀번호로 바꿉니다.

## 4. 홈 화면에 추가하기

**아이폰(반드시 Safari로 접속)**
1. 아래 공유 버튼(네모에서 화살표가 위로 나가는 모양)을 누릅니다.
2. **"홈 화면에 추가"**를 누릅니다.
3. 다음부터는 **홈 화면에 생긴 아이콘**으로 실행합니다(Safari에서 바로 쓰면 알림이 오지 않습니다).

**안드로이드(Chrome으로 접속)**
1. 메뉴(점 세 개) → **"앱 설치"** 또는 **"홈 화면에 추가"**를 누릅니다.

## 5. 알림 받기

- **MY** 탭 → **알림 받기**를 누릅니다.
- 알림을 허용할지 물어보면 **허용**을 누릅니다.
- 나중에 알림이 안 오는 것 같으면, MY 탭에 한 번 다시 들어가 보세요. 자동으로 다시 연결됩니다.

## 6. 상품 정보 확인하기

- 하단 **프로모션** 탭에서 가격/사은품/행사 등 최신 상품 정보를 확인합니다.
- 최근에 새로 등록되거나 중요하게 바뀐 상품에는 **NEW** 표시가 붙습니다.

## 7. 공지 확인하기

- 하단 **공지** 탭에서 본사 공지를 확인합니다.
- "꼭 확인" 표시가 된 공지는 내용을 읽은 뒤 **확인 완료** 버튼을 눌러주세요.
